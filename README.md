# Earnie's Super Ear Trainer

Phone-friendly dual N-back style ear training. Tap the piano key of the note played N steps back.

- One octave, 12 notes, with sharps/flats labelled.
- Session length = 20 + N × 8 trials.
- N goes up when you score above 90%, down at 60% or below.
- Screen stays awake during a session (where the browser supports the Wake Lock API).

## Run

Open `index.html` in a browser. No build step, no dependencies.
